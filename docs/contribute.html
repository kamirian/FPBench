1. Run FPBench

FPBench evaluates foundation potentials through ASE calculators. Adding one means a single entry in the component's POTENTIAL_REGISTRY — no metric or analysis code changes. Full procedure: Adding a Potential.

  1. Register — one entry in the component's POTENTIAL_REGISTRY.
  2. Generate — the generator writes one standalone script per job. Nothing is submitted.
  3. Run — on your own machine or cluster. FPBench generates jobs; it does not execute them.
  4. Merge — validates each job against the shared reference and writes the standardized results file.
  5. Analyze — the analysis notebook reads that file and reproduces the leaderboard tables.

Example: register your potential

A representative entry. my_fp, MyFPCalculator and the paths are illustrative placeholders. Field names differ between components, so copy an existing entry from the generator notebook of the component you are evaluating rather than this one. 

"my_fp": {
    "mlip_name":     "my_fp",
    "site_pkgs":     "/path/to/my_fp_env/lib/python3.10/site-packages",
    "venv_activate": "/path/to/my_fp_env/bin/activate",
    "python":        "/path/to/my_fp_env/bin/python",
    "model_path":    "/path/to/checkpoints/my_fp_model.pt",
    "calc_setup":    textwrap.dedent("""
        from my_fp.calculators import MyFPCalculator
        calc = MyFPCalculator(
            model_paths=[MODEL_PATH],
            device="cpu",
            default_dtype="float64",
        )
    """).strip(),
},
Notes on the registry entry

The generator substitutes MODEL_PATH from the entry's model_path. Where a package ships its own weights, set model_path to None. Values still beginning with /path/to/ raise an explicit error rather than producing a job script that fails later. One environment per FP family is recommended, since FP packages pin incompatible PyTorch and ASE versions.

For each component evaluated, submit the final results file produced by the merge step. The tabs below show the expected file format and example analysis code.

FieldMeaning

dft_force_magnitude

atom_indexZero-based position of the atom within its own structure; restarts at 0 for each structure.

Cartesian FP forces with structure IDs and matching atom ordering are preferred, as they allow us to calculate force errors directly against the DFT reference.

Example: convert forces to standardized results

Convert Cartesian DFT and FP forces into standardized per-atom force errors.

Run from: Force_error/analysis/
Requires: numpy

import json, sys
sys.path.insert(0, "../scripts")
from force_results import build_force_results

ex = json.load(open("../examples/mace_matpes_cartesian_force_example.json"))

force_results = build_force_results(
    ex["dft_forces"],            # DFT reference forces: one (N_i, 3) array per structure
    {"MACE": ex["fp_forces"]},   # FP forces aligned with the DFT structures and atom order
    ex["structure_ids"],
)
print(len(force_results["MACE"]["dft_force_magnitude"]), "atoms")
# 25 atoms

Example: calculate force-error metrics

Calculate a metric table using the included example data. To analyze your own results, replace the example-data preparation with the commented file-loading code.

Run from: Force_error/analysis/
Requires: numpy pandas matplotlib

import json, sys
sys.path.insert(0, "../scripts")
from force_results import build_force_results
from force_error_metrics import build_highly_accurate_force_fraction_table

ex = json.load(open("../examples/mace_matpes_cartesian_force_example.json"))
force_results = build_force_results(ex["dft_forces"], {"MACE": ex["fp_forces"]},
                                    ex["structure_ids"])

# To analyze a standardized results file, replace the example-data preparation above with:
# with open("../data/<your-dataset>_force_results_standardized.json") as f:
#     force_results = json.load(f)["models"]

# Map standardized fields to the names expected by the analysis functions.
all_results = {
    model: {"F_dft":      d["dft_force_magnitude"],
            "F_fp":       d["fp_force_magnitude"],
            "deltaF":     d["force_magnitude_error"],
            "deltaTheta": d["force_angle_error"],
            "e_vec":      d["force_vector_error"]}
    for model, d in force_results.items()
}

table = build_highly_accurate_force_fraction_table(all_results, [0.01, 0.05, 0.10])
print(table)
#       0.01  0.05  0.10
# MACE  12.0  56.0  84.0      <- Example output for the 25-atom subset.

table.to_csv("force_highly_accurate_fraction.csv")

Example: validate results and calculate hull metrics

Validate the example results and calculate a hull metric table.

Run from: Phase_stability_ordering/analysis/
Requires: numpy pandas matplotlib pymatgen

import json, sys
sys.path.insert(0, "../scripts")
from convexhull_analysis_utils import (
    build_phase_stability_ordering_results,
    validate_phase_stability_ordering_results,
    build_combined_hull_table,
)

with open("../examples/phase_stability_ordering_demo_data.json") as f:
    demo = json.load(f)

results = build_phase_stability_ordering_results(
    reference_data=demo["reference_data"], fp_results=demo["fp_results"],
)
FPS = list(demo["fp_results"])
MODEL_NAMES = {"mace": "MACE"}

report = validate_phase_stability_ordering_results(
    dft_hull=results["dft_hull"],         fp_hull_by_fp=results["fp_hull"],
    dft_ordering=results["dft_ordering"], fp_ordering_by_fp=results["fp_ordering"],
    fps=FPS,
)
# prints a coverage report: 10/10 hull candidates, 1/1 ordering group,
# with missing and non-success records broken down per FP and protocol

hull_table, hull_details = build_combined_hull_table(
    results["dft_hull"], results["fp_hull"], FPS, MODEL_NAMES,
)
print(hull_table)
# Average energy error 69 meV/atom, ground-state agreement 50.0% (relax)

hull_table.to_csv("phase_hull_table_demo.csv")

Example: validate results and calculate reference barriers

Validate the example results and calculate the DFT reference barriers for one pathway.

Run from: Ion_migration_NEB/analysis/
Requires: numpy pandas matplotlib pymatgen ase scikit-learn

import json, sys
sys.path.insert(0, "../scripts")
from neb_analysis import validate_neb_analysis_inputs, build_neb_analysis_results

with open("../examples/ion_migration_neb_demo_data.json") as f:
    demo = json.load(f)

reference_data = demo["reference_data"]
fp_results     = demo["fp_results"]
fp_order       = list(fp_results["models"].keys())

validation = validate_neb_analysis_inputs(
    reference_data, fp_results, expected_pathways=None, fp_order=fp_order,
)
print("validation ok:", validation.ok)
# validation ok: True

analysis = build_neb_analysis_results(
    reference_data, fp_results, expected_pathways=None,
    fp_order=fp_order, validate=True,
)
print(analysis.dft_path_metrics_df)
#     ICSD  Path  Pathway Topology  energy_forward_barrier  energy_backward_barrier
# 0  29966     8       Normal-Hill                0.165365                 0.139784

analysis.dft_path_metrics_df.to_csv("neb_dft_path_metrics_demo.csv")
